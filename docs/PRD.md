# Ets2SaveEditor 产品需求文档（PRD · 简洁版）

> 文档版本：v0.1（草案）　|　作者：产品经理 许清楚（Xu）　|　状态：待评审
> 参考项目：TS-SE-Tool（C#/.NET Framework WPF，ETS2/ATS 存档修改器）

---

## 1. 产品目标

| # | 目标 | 说明 |
| --- | --- | --- |
| G1 | **安全可读写任意存档** | 自动识别明文 / zlib 压缩 / 加密(ScsC) / 二进制(BSII) SII 格式，无损加载并**按原格式写回**（加密 ScsC 重新加密、zlib 重新压缩、其余明文），不对原文件做不可逆破坏。 |
| G2 | **覆盖核心修改场景** | 提供金钱、等级、技能、车库、卡车修理 / 加油等高频修改能力，对齐参考项目核心功能。 |
| G3 | **可扩展的现代化架构** | 以 `Core`（解析 + 领域模型 + 游戏数据）与 `WPF`（MVVM 交互）分层，便于社区贡献与后续扩展（货运市场、分享、编队等）。 |

---

## 2. 用户故事

- **休闲玩家（As a casual player）**：我希望一键定位并打开我的 Steam 存档，快速把金钱改满、把卡车修好加满油，这样我就能轻松体验游戏而不被资源卡住。
- **硬核玩家（As a hardcore player）**：我希望精确编辑技能点、车库与卡车颜色涂装，并导出 / 导入涂装与卡车位置，这样我能在多台设备或多套存档间同步我的个性化配置。
- **货运任务作者（As a freight market author）**：我希望基于已访问城市创建自定义货运任务并编辑货物市场，这样我能设计专属的运输路线与玩法。
- **Mod 作者 / 社区贡献者（As a community contributor）**：我希望核心解析逻辑独立、接口清晰，这样我能方便地扩展新的游戏数据（城市 / 货物 / 公司）或新增格式支持。

## 3. 需求池（按优先级）

> 优先级：**P0=必须（核心）**，**P1=应当（重要）**，**P2=可选（增强）**。

### P0 — 核心（必须）

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| P0-1 | 加载任意存档 | 支持手动指定路径，自动识别明文 / zlib 压缩 / 加密(ScsC) / 二进制(BSII) SII；zlib 与加密均使用托管代码解密解压；失败的存档给出明确错误提示且不破坏原文件。 |
| P0-2 | 保存存档 | 按原格式写回（`ScsC` 重新加密 / zlib 重新压缩 / 明文），保留原始结构；覆盖加密源文件前强制备份（与自动备份开关无关）。 |
| P0-3 | 修改账户金钱 | 可编辑 `bank.money_account`；支持数值校验（非负）。 |
| P0-4 | 修改玩家等级 | 可编辑 `player.level`。 |
| P0-5 | 修改技能 | 可编辑驾驶技能项（如长距离、危险品、贵重货物、易碎货物、长途、紧急交付等）。 |
| P0-6 | 购买 / 升级车库 | 可解锁或升级车库条目；与资金 / 城市状态联动。 |
| P0-7 | 卡车修理 / 加油 | 一键修复卡车损坏、加满燃油。 |

### P1 — 重要（应当）

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| P1-1 | 编辑 / 分享卡车与挂车用户颜色 | 可编辑涂装颜色；支持导出 / 导入颜色配置。 |
| P1-2 | 访问城市 | 标记城市为已访问（解锁快速旅行点）。 |
| P1-3 | 从已探索城市抓取货物 | 基于已访问城市生成可用货物列表。 |
| P1-4 | 创建自定义货运市场任务 | 支持新建 Freight Market 任务（起点 / 终点 / 货物 / 报酬）。 |
| P1-5 | 基础货物市场编辑 | 可浏览并编辑已有货物市场条目。 |
| P1-6 | 修理挂车 | 一键修复挂车损坏。 |
| P1-7 | 分享卡车涂装 | 导出 / 导入卡车涂装完整配置。 |

### P2 — 增强（可选）

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| P2-1 | 分享卡车位置 | 导出 / 导入卡车坐标。 |
| P2-2 | 分享 GPS 路径 | 导出 / 导入导航路径。 |
| P2-3 | 编队控制包（Convoy Control） | 将多个卡车位置打包为编队包。 |
| P2-4 | 3NK 格式支持 | 在 明文 / zlib / 加密(ScsC) / 二进制(BSII) 基础上，扩展解析参考项目 `SII_Decrypt.dll` 的 3NK 格式。 |
| P2-5 | Mod 扫描 | 扫描并加载 Mod 中的游戏数据（城市 / 货物 / 公司），增强兼容性。 |

## 4. UI 设计稿（文字线框）

主窗口为 **标签页（Tab）** 结构，顶部为菜单栏（文件：打开 / 保存 / 备份、帮助），下方为各功能标签：

```text
┌──────────────────────────────────────────────────────────────┐
│  Ets2SaveEditor            [文件] [编辑] [帮助]                │
├──────────┬───────────────────────────────────────────────────┤
│ 档案     │  玩家档案 / Profile                                  │
│ Profile  │  ┌─────────────────────────────────────────────┐  │
│ ───────  │  │ 存档路径: [__________________] [浏览][打开] │  │
│ 车库     │  │ 玩家等级: [  ]   技能: [ ] [ ] [ ] [ ] [ ]  │  │
│ Garages  │  │ 账户金钱: [          ]   [应用]             │  │
│ ───────  │  └─────────────────────────────────────────────┘  │
│ 卡车     │                                                     │
│ Truck    │                                                     │
│ ───────  │                                                     │
│ 挂车     │                                                     │
│ Trailer  │                                                     │
│ ───────  │                                                     │
│ 货运市场 │  标签内容随选择切换（见下）                          │
│ Freight  │                                                     │
│ ───────  │                                                     │
│ 货物     │                                                     │
│ Cargo    │                                                     │
│ ───────  │                                                     │
│ 设置     │                                                     │
│ Settings │                                                     │
└──────────┴───────────────────────────────────────────────────┘
```

- **档案 / Profile**：存档路径（浏览 / 打开）、玩家等级、技能勾选、账户金钱；「应用 / 保存」按钮。
- **车库 / Garages**：车库列表（已购 / 可解锁）、购买 / 升级操作、关联城市状态。
- **卡车 / Truck**：当前卡车信息、修理 / 加油、用户颜色编辑、涂装导出 / 导入、卡车位置分享。
- **挂车 / Trailer**：挂车列表、修理、用户颜色编辑。
- **货运市场 / FreightMarket**：自定义任务创建（起终点 / 货物 / 报酬）、任务列表管理。
- **货物 / Cargo**：货物市场条目浏览 / 编辑、从已访问城市抓取货物。
- **设置 / Settings**：存档默认路径、Steam 路径探测开关、保存前自动备份开关、语言、关于 / 免责声明。

## 5. 待确认问题（Open Questions）

1. **平台范围**：首个版本是否仅支持 **Windows（WPF）**，还是需规划跨平台（如 .NET MAUI / Avalonia）？当前技术决策为 WPF（Windows）。
2. **3NK 格式**：参考项目 `SII_Decrypt.dll` 的 3NK 格式是否纳入首版范围，还是后置到 P2？当前方案已实现 明文 / zlib / 加密(ScsC) / 二进制(BSII) 四种，仅 3NK 待定。
3. **Steam 存档路径探测**：自动探测 Steam 存档路径的方式（注册表 / 常见路径规则 / 用户手动指定优先）如何取舍？
4. **保存前备份策略**：默认是否开启「保存前自动备份」，备份文件命名与保留策略如何设计？
5. **数值边界与校验**：金钱 / 等级 / 技能是否设置上限（对齐游戏内上限），超限时的处理策略？
6. **Mod 数据来源**：P2 的 Mod 扫描是否需要支持创意工坊订阅目录解析？其优先级是否高于编队控制包？
